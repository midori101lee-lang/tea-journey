# 《茶游记》

> 中国每一座茶山，都有自己的故事。

《茶游记》是一场可以玩的中国茶山游历。

你可以走进一座茶山，认识当地的人，采茶、制茶、泡茶、逛茶集市；
在一次次走动与闲聊里，慢慢把中国茶文化的门道摸出来。

这里没有战斗，也没有等级。玩家的成长不是变强，
而是从「老板说啥我都信」，慢慢变成「故事讲得挺好，但我还是先喝一口」。

## 当前版本

第一站：**武夷山**（目前唯一可游玩的茶区）。

- **采茶** —— 跟着阿秀学「开面采」，判断茶青太嫩 / 合适 / 太老
- **制茶五步** —— 倒青（两晒两晾）→ 做青（摇青 + 静置）→ 炒揉（双炒双揉）→ 焙火（看火候），
  加上采茶共五道工序，每一步都是可以上手玩的小互动
- **三款岩茶** —— 肉桂、水仙、大红袍，各有自己的脾气
- **泡茶** —— 盖碗泡法：温杯 → 投茶 → 注水 → 闻香 → 出汤 → 品饮，泡完由老茶客周伯点评
- **茶集市** —— 亲手做过三种茶各一锅后开市。
  可以自己摆摊卖茶，也可以逛别人的摊：看看茶、问问老板、淘回家泡，
  偶尔捡个漏，偶尔买贵了，偶尔还会遇上「免费请你喝一口」的王霸茶 😈
- **茶山手账** —— 茶客手记、茶山足迹、茶具收藏、茶文化漫画、旅行明信片
- **九龙窠母树** —— 看得到、喝不到的活标本，附一张母树明信片
- **山路偶遇** —— 主动去山路上逛逛，会随机遇见采茶阿姨、三轮车茶农、茶商老贾、林姑娘……
  十来位山里人，有的聊天，有的塞你一包茶，有的什么也没发生
- **熟练度** —— 只用「初学 / 入门 / 熟手 / 老练」四档文字呈现，不显示数字

> 游戏进度保存在浏览器本地（localStorage），换设备不会同步。

## 游戏特色

- **真实茶文化 + 游戏化体验** —— 工序、称呼都按真实来（武夷山叫「倒青」不叫「摊晾」，叫「焙火」不叫「干燥」），
  只是把复杂度降下来，保留真实的工艺因果
- **东方手绘绘本风格** —— 场景与人物以手绘质感的画面呈现，没有数值面板、没有评分条
- **NPC 与茶山旅行** —— 老陈、阿秀、岩伯、周伯、林姑娘各管一段，不重复讲同一件事；
  认识的人会记住你，下次见面招呼也不一样
- **制茶与泡茶互动** —— 制茶看手感，泡茶看时机，结果用一句自然语言和品质等级告诉你
- **茶集市与探索** —— 买茶不为奖励，只为「这包可能比我做的好」；
  捡漏和买贵都不给数值惩罚，只让周伯在喝茶时轻轻点你一句

## 技术

- **React 18** + **TypeScript** + **Vite 5**，状态管理用 **Zustand**
- 核心逻辑与视图分层：`src/core`（纯数据与规则）不引入 React
- 美术以 **内联 SVG** 为主，场景背景与人物立绘用 **WebP 位图**；不依赖 UI 组件库与动画库
- 音效为零音频文件的合成方案；存档走 localStorage 并带版本迁移
- 同一套代码支持两种构建：**Web 版**（完整游历）与 **小红书版**（线性精简流）
- 代码托管 **GitHub**，站点托管 **Cloudflare Pages**

## 本地运行

```bash
npm install        # 安装依赖
npm run dev        # 本地开发（默认 http://localhost:5173）
npm run build:web  # 构建 Web 版，产物在 dist/
npm run preview    # 预览构建产物
```

其他常用脚本：

```bash
npm run typecheck  # 类型检查
npm run dev:xhs    # 小红书版开发
npm run build:xhs  # 构建小红书版
```

> 环境要求：Node.js 18 及以上（仓库内 `.nvmrc` 指定为 20）。

## 项目结构

```
src/
  core/        类型、茶叶 / NPC / 场景 / 漫画等数据、存档与迁移（不含 React）
  features/    采茶制茶、泡茶、茶集市、手账、偶遇、地图等玩法模块
  components/  场景舞台、NPC 立绘与通用 UI
  store/       Zustand 全局状态与场景导航
  styles/      设计变量与基础样式
public/assets/ 场景背景、NPC 立绘、茶具、知识卡等静态资源
docs/          产品方案与设计资料
```

## 部署

项目通过 **GitHub + Cloudflare Pages** 自动部署：推送到 `main` 分支后，
Cloudflare Pages 会执行 `npm run build:web` 并把 `dist/` 发布出去。

| 配置项 | 值 |
| --- | --- |
| Framework preset | None |
| Build command | `npm run build:web` |
| Build output directory | `dist` |
| Node version | 20 |

站点是纯静态的，没有客户端路由，刷新任意页面都不会 404。
