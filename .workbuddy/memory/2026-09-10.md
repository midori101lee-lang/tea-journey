## 出汤机制 + 茶评价系统优化（本轮，未 commit/push）

### 新增 `src/core/data/brewEval.ts`（core 纯逻辑，无 React/DOM）
- `TEA_STEEP`：三茶（含 wangba）各含 `window{start,end}`（最佳出汤窗口，t 空间不暴露秒数）+ `steepRate`（仅微调，避免"背秒数"）+ `stages[]`/`stageCut[]`（3~4 段实时茶汤状态文案）。窗口差异=判断点/容错率/反馈节奏：肉桂[0.46,0.68]早而窄→果断；水仙[0.38,0.78]宽→从容；大红袍[0.5,0.8]中等稍后→观层次。

### 天气系统 V0.1（用户 2026-09-10 晚，轻量天气）
目标：让玩家"今天的武夷山和昨天不一样"，天气自然参与制茶（仅倒青/做青），不新增玩法/数值/外部 API。

#### day 现状（探查结论）
- `player.day` = 当前茶区天数，`regionDays` 分区记录，`currentRegion` 标识茶区。天气用 `getWeatherForDay(day, region)` 复用，不建第二套日期系统。

#### 新增/改动文件
- `src/core/data/weather.ts`（新增，core 纯逻辑无 React/DOM）：4 种天气 `WeatherId=sunny/cloudy/mist/rain`，`WEATHER_CONFIG{icon,name,shortDescription,rate,zuoqing{force,decay,label},visual}`；`getWeatherForDay(day,region='wuyishan')` 用 hashDay 确定性伪随机（同一 day+region 永远同天气，不 random）；`currentWeatherId(player)`；`makingRate(id)`；`zuoqingWeather(id)`；`NPC_WEATHER_LINES`（老陈/阿秀/周伯少量随感）+`getNpcWeatherLine`。
- `src/features/making/MakingFlow.tsx`：进制茶时算一次 `weatherId` + `weatherRate` + `zuoqingW`，传子步骤；不显示数值、不改最终品质。
- `src/features/making/steps/DaoqingStep.tsx`：加 `weatherRate?` prop，setInterval 状态增量 ×rate（晴略快/雨略慢）。
- `src/features/making/steps/ZuoqingStep.tsx`：删原 `Math.random()` 抽 WEATHERS（规格点名避免的"每次进重 random"），改接收 `weather:{force,decay,label}` prop，理想力度区间偏移 force、青气衰退 ×decay。
- `src/components/Weather.tsx`（新增）：`WeatherBadge`（武夷山首页天气卡）、`WeatherOverlay`（NpcStage 背景层 CSS overlay，pointer-events:none）、`NpcWeatherAside`（NPC 天气随感，无台词时返 null）。
- `src/components/NpcStage.tsx`：bg 之后、figure 之前注入 `<WeatherOverlay id={currentWeatherId(player)} />`，over bg 但低于 NPC/对话。
- `src/features/world/MapView.tsx`：首页顶部加 `<WeatherBadge id={currentWeatherId(player)} />`。
- `src/app/WebApp.tsx`：teahouse/garden/teatable 三场景加 `<NpcWeatherAside npcId=laochen/axiu/zhoubo>`，仅在 `!activeEncounter && revealed` 时显示。
- `src/styles/base.css`：`.weather-overlay` 及 sunny/cloudy 渐变、mist 漂移动画、rain 雨丝动画、`.weather-badge` 卡片样式；纯 CSS，不增素材。

#### 设计要点（对照规格）
- 4 种天气：☀️晴(rate1.1)/☁️多云(1.0)/🌫️山雾(0.9)/🌧️小雨(0.85)；只影响倒青(状态变化速度)与做青(force/decay)，不动采茶/炒揉/焙火/泡茶/售价/品质。
- 天气是环境条件非 Buff/Debuff，不显示数值、不决定结果、不导致必然失败（rate ∈ 0.85~1.1）。
- 完全本地、零外部天气 API；复用 day；region 参数预留杭州/福州/潮州（V0.1 仅武夷山）。
- NPC 天气台词不进对话触发链（aside 形式），周伯品茶仍严格走既有 zhouBoAdvice（九龙窠 saw 后永不重推）；天气无法绕过。
- 性能：纯 CSS overlay，不增图片/视频/网络请求，不增加首屏加载。
