## 竹木茶承「向前(向下)移动」承托关系微调（第 3 轮茶席视觉）
- 问题：茶承尺寸(上轮已放大到视觉宽 52%)够了，但**层级/前后位置偏靠后**——看起来像「茶承在茶具后面」而非「茶具摆在茶承上」。用户明确：这里的「往前」= 向屏幕下方/玩家方向移动（Y 增大），不是 z-index。
- 根因(量化)：茶承图 2.5:1，锚点在底边中心；原 top=73.2 → 茶承可见范围 y61.9~73.2，而三件主茶具底边在 y70.6~71.6，即茶具落在茶承**前 1/3**，茶承**后 2/3 空着**在茶具身后 → 读成「背板」。
- 解决：**只调 assist 锚点，尺寸不动**。assist `top 73.2 → 74.4`、`left 51→50.5`、`width 52→50`、`order 1` 不变、`hit` 不变（仍是 {43,72.5,17.5,4} 小矩形）。新范围 y63.1~74.4。
- **几何硬约束（重要）**：桌面可用带只有 viewBox y30~95 = 舞台 y≈66.1~73.2（7.1% 高），而 50% 宽茶承高 11.25% —— **茶承天生比桌面带高**。茶承前缘最多只能到桌面/前围板底(y≈74.4 舞台%)，再往下就悬到桌腿外。所以**向前移动上限≈+1.2%**；想让茶具真正居中在茶承上（需再下移 ~2%）会掉出桌面。若后续还想更居中，只能：①茶具(brew/taste/share)整体上移~1.5% ②加深茶桌桌面带 —— 均超出「只调 assist」范围，待用户拍板。
- 茶承图是 1981×793 紧裁（alpha bbox 仅顶部留 21px），**不能靠裁切变浅**；非等比缩放被用户禁止。
- 校验：茶具组合占地 x30.75~71.25，茶承 x25.5~75.5 → 两侧留白 5.2%/4.3%（真承托）。elementFromPoint 五热区中心全部命中自身（全摆/全空/混合/刷新后）。tray-only 时茶承位于桌面**前中部**、不显靠前。travel 模式 0 个普通热区、旅行套组锚点未动。

## 采茶茶梢分布随机化（有界随机 + 位置×叶态解耦）
- 根因：PickingStep 里 `x = 7 + ((i*37) % 74)` —— 37*2=74，所以 x 只有 **7 / 44 两列**（y 用 `(i*53)%46` 错开）；且 `kindOf(i)` 用 `i%12` 定叶态、坐标也由 i 定 → **位置即明牌**，多玩几次就能背位置。
- 方案：新增纯函数模块 `src/core/making/pickingLayout.ts`（无 React/DOM，可模拟校验）：
  - `buildPickingLayout({seed,count,mode})`：拒绝采样（有界随机）+ 最小间距；叶态 `kindBag` 洗牌后分配 → 位置与叶态彻底解耦；`rot ∈ ±8`、`scale ∈ 0.96~1.04`。
  - 常量（舞台 %）：`SHOOT_BOX 11.1×10.4`（≈44×59.4px/390×560）；`SPAWN {x:4~55, y:21~72}`；`BLOCKED=[竹篮 33~67×76~100, 采茶人 67~100×22~70]`（实测：竹篮 x34.5-65.5/y77.8-94、阿秀 x69-96/y25.1-68）；`MIN_SEP 0.9`（按盒归一化）。
  - **配比与旧版逐字一致（难度不变）**：开面采 good7/tender3/old2；嫩芽采 bud1 5/bud2 4/old3。
- PickingStep：删掉 kindOf 与坐标公式，改 `useState(() => seed)` 惰性钉住 + `useMemo([seed,attemptCount,mode])` → **同一局内任何重渲染都不重排**；transform 加 `scale()`。
- 调试口：DEV-only `?pickseed=12345`（固定/切换布局；prod 构建已 DCE，dist/dist-xhs 里 `pickseed` 命中 0）。⚠️ 测试时 URL 残留 pickseed 会固定布局，用 `history.replaceState({}, '', '/')` 清。
- 关键实测数据：pick-stage = 398×571（aspect 390/560），`.pick-shoot` 锚点是**左上角**（无 translate -50%）。
- 测试：400 seed 断言全过（越界 0/压竹篮人 0/最小间距 0.9/配比/同 seed 确定、相邻 seed 大不同/最左最上叶态三态都出现/每局 x 去重≥6）；浏览器：连续 5 局布局明显不同且自然；**教学推进 3 次重渲染位置分毫不动**；**拖动采下一棵后其余 11 棵完全没动**；杭州嫩芽采（九曲红梅，阿青+杭州茶园）正常；tsc+build:web+build:xhs 全过。
