## 1. 已冻结设计

> 以下为不再讨论、直接进入开发的内容。

### 1.1 产品层

| 项 | 冻结内容 |
|---|---|
| 产品定位 | 一场可以玩的中国茶山游历。中国每一座茶山，都有自己的故事 |
| 不是什么 | 茶知识考试 / 茶叶百科 / 专业制茶模拟器 / 感官审评软件 / 旅游宣传册 / RPG 数值养成 |
| 玩家身份 | 茶客 / 茶山游历者 |
| 核心驱动 | 探索欲 > 收集欲 > 成长欲 > 知识学习；下一座山是好奇心兑现，不是任务奖励 |
| 核心循环 | 进入茶区 → 认识当地人 → 采茶 → 制茶 → 茶叶入茶篓 → 泡茶/赠送/卖 → NPC 点评 → 熟练度 → 听来一句闲话（线索）→ 主动出发下一座山 |
| 第一章 | 武夷山（先做一座山，再做整个中国） |
| 制茶定位 | 制茶是进入茶世界的第一把钥匙，不是终点 |

### 1.2 工艺与玩法

| 项 | 冻结内容 |
|---|---|
| 现实工艺骨架 | 采摘 → 倒青/萎凋 → 做青 → 初炒 → 初揉 → 复炒 → 复揉 → 初焙 → 扬簸 → 凉索 → 拣剔 → 复焙 → 吃火 → 团包 → 补火 → 装箱（DB35/T 2157-2023） |
| 非遗关键语汇 | 复式萎凋 / 看青做青 / 看天做青 / 走水返阳 / 双炒双揉 / 低温久烘 |
| 五个可玩节点 | 采茶 → 倒青 → 做青 → 炒揉 → 焙火 |
| 简化规则 | 初焙并入焙火；扬簸/凉索/拣剔/团包/装箱 只在结果页旁白带过 |
| ① 采茶 | **开面采**判断，**三类**：太嫩 / 合适 / 太老（C7） |
| ② 倒青 | 铺开 → 观察 → 两晒两晾 → 判断收叶；反馈用"叶片开始柔软了""青气退了一些" |
| ③ 做青 | 观察 → 摇青（力度+时长）→ 静置走水 → 再判断；3–4 轮；**无固定答案**；单日天况影响；叶缘转红 |
| ④ 炒揉 | **一个 Step，两轮内部操作**（炒青→趁热揉捻→复炒→复揉）；"趁热"用 3 秒窗口表达（Q1） |
| ⑤ 焙火 | 动态火候指针；绿区随 茶种/前序表现/轮次/熟练度/随机 漂移；**稳 > 准**；火功 轻/中/足；**不是温度越高越好** |
| 单局时长 | 见第 3 节 A 项（待确认，不自行决定） |

### 1.3 系统与表达

| 项 | 冻结内容 |
|---|---|
| 品质等级 | **失败 / 普通 / 良好 / 上品**（C2）；**取消神品**（Q2） |
| 结果表达 | 等级 + 一句自然语言 + 可售茶钱 + 火功；**前台禁止任何专业审评数字** |
| 失败机制 | 可以失败；**不扣茶钱**（Q3 修订）；消耗的是「本轮鲜叶」（本轮原材料，非库存，**不存在"鲜叶 −1"**）；**失败仍产出失败等级成茶，进入背包 / 茶叶记录**（可自泡、可留记录，暂不适合斗茶）；失败必须有可归因原因；失败也给熟练度 |
| 熟练度 | 单一不拆分；**前台不显示数字与 +N**；档位：**初学 / 入门 / 熟手 / 老练**（C1） |
| 茶篓 | 按 茶种 + 品质 + 火功 堆叠；可泡 / 可送 / 可卖 |
| 茶钱 | 游戏自有经济，不复制现实价格；普通 10–20 / 良好 20–30 / 上品 30–50（游戏参数，可调） |
| 泡茶 | **8 步**：烧水 → 温盖碗 → 投茶 → 注水 → 观察茶汤 → 闻香 → 判断出汤 → 完成品饮（C6）；MVP 必须有（Q4） |
| 出汤 | 动态判断；**秒数与投茶量是游戏参数，不伪装成专业标准** |
| 三茶 | 肉桂 🔥张扬派「先闻香」/ 水仙 🌿温润派「喝的是汤」/ 大红袍 🟤平衡派「喝了才知道」 |
| 三茶差异 | **全部降级为 `teaGameProfile` 游戏参数**，不属于知识系统（C3） |
| 六棵母树 | 轻量：NPC 对话 + 1 个漫画/知识卡片；**不可采、无坐标、无掉落**；结果页注「此大红袍，非九龙窠那几棵」（Q5 + C5） |
| 知识获取顺序 | 先玩 → 看到变化 → NPC 说一句 → 好奇 → 漫画/手账补充；不做知识弹窗与 500 字百科 |
| 传说 | 必须标【传说】/「民间流传着这样一个故事」 |
| NPC 语言 | 认真做茶，但不端着；禁止百科腔与旅游宣传腔 |
| 双平台 | Core/Shared 共享 ≥85%；只用 feature flag + `params.standard/casual` 调难度；禁止散落 `if (isXhs)` |
| 技术底座 | Vite + TS + React18（xhs 端 Preact alias）+ Zustand + CSS 变量 Token；全内联 SVG；WebAudio；StorageAdapter + schema v3 |

### C8 · 老陈 / 阿秀职能边界（已裁决，2026-09-08 采用方案 2）

> 原始冲突：C4 把老陈定义为"茶农 + 贯穿式 NPC"后，与阿秀（采茶人）在"带你采茶"上重叠。

保留 5 人结构，不新增 NPC、不做好感度系统：
- **老陈 = 茶农兼茶馆老板**：茶馆、山里生活、人情、茶山旧闻、母树、交易、熟客关系；**不负责采茶教学，也不负责制茶教学**
- **阿秀 = 采茶人**：茶园、茶青、采茶、开面采、茶季、劳作；**不负责母树故事，不承担茶文化百科**
- 两者都懂茶，但**不承担相同教学职能**
- 详细设计见 `docs/茶游记_武夷山NPC设计_V1.0.md`（含职能对照表、知识所有权矩阵、老陈七次相遇链、台词包预算）

### 附：M1 的口径梳理（历史记录，已裁决）

> 以下为 M1 裁决前的口径梳理，**最终口径以第 8 节「开发前确认状态」为准**，供追溯。

**A · 制茶核心流程时长（五节点）**
- V0.3 §5.1：**约 3 分 10 秒（standard）／约 100 秒（casual）**
- 资料库 §47：**标准约 3 分钟／轻量约 100 秒**
- 结论：两份文档对 A 的口径**一致**，A ≈ 3 分钟（快速档 ≈100 秒）

**B · 武夷山第一日完整体验时长（茶馆→采茶→制茶→泡茶→点评→手账→线索）**
- V0.2 曾写：首次 8–10 分钟（**V0.3 未继承，仅作历史参考，已失效**）
- 最终口径：B 第一日**首次完整体验目标 ≈ 8–12 分钟**（见第 8 节）。
- **补充说明：8–12 分钟是产品目标时长，不是硬性限制。** 它用于把握首日的叙事与节奏节奏预算，不要求玩家必须在该区间内完成；体验偏长或偏短都不会触发惩罚或截断。

**小红书端与 Casual 的时长统一**
- 历史记录中曾并存「Casual ≈ 100 秒」与「小红书 ≤ 90 秒」两种表述，现统一为：
  **小红书端制茶体验目标约 90–100 秒，以实际测试为准。**
- 不为了压到 90 秒而删减 P0 核心玩法（采茶/倒青/做青/炒揉/焙火 五节点均保留）。

**可能产生产品理解问题（已随裁决消解）**
1. 「3 分钟」曾可能被误解为第一日全程——现明确**仅指代 A 制茶核心流程**，对外不宣传「3 分钟玩完整个第一日」。
2. 资料库 §47 的「标准体验约 3 分钟」scope 已明确为制茶核心流程，避免压缩茶馆、泡茶、故事的叙事空间。
3. B 原无定义值——现已给出 8–12 分钟产品目标（非硬限），可用于评估首日节奏（首个奖励/线索/收尾）。

## 5. P0 最终范围

> 以资料库 §53 与 Q4/Q5/C5 为准。V0.3 §19 中写为 P1 的泡茶、图鉴手账、母树，**一律上调 P0**。

### P0 · 世界与流程
1. 开场：竖排标题 → 第一站 武夷山 → [进山]
2. 茶馆开场：老陈递茶（揭盖 → 热气 → 分汤）→「光喝有什么意思？要不要自己做一锅？」
3. 地点导航：茶馆 / 茶园 / 制茶坊 / 茶桌
4. 茶园：阿秀 + 选茶

### P0 · 制茶五节点
5. 采茶（三类判断）
6. 倒青（两晒两晾）
7. 做青（摇青 + 静置，3–4 轮，天况影响）
8. 炒揉（一个 Step 两轮，趁热窗口）
9. 焙火（动态指针，火功累积）

### P0 · 结果与资源
10. 成茶结果（失败/普通/良好/上品 + 一句评价 + 茶钱 + 火功）
11. 茶篓（入篓 / 卖 / 留着）
12. 茶钱经济（游戏自有）

### P0 · 闭环（Q4 强制）
13. **泡茶 8 步**（烧水 → 温盖碗 → 投茶 → 注水 → 观察茶汤 → 闻香 → 判断出汤 → 完成品饮）
14. 泡茶后 NPC 点评（周伯；岩伯插话）

### P0 · 长期动力（C5 上调）
15. **图鉴 / 茶山手账**（去过的地方、做过的茶、遇见的人、听来的传闻）
16. **六棵母树**（NPC 对话 + 1 张漫画/知识卡；轻量，不可采）
17. 基础漫画系统（至少支撑母树那一张）

### P0 · 系统底层
18. 熟练度（内部数值，前台只显示 初学/入门/熟手/老练）
19. 玩家状态与存储（schema v3 + 迁移 + 隐私模式降级）
20. 数据分层：`TeaFact(level, source)` / `TeaCopy(kind)` / `teaGameProfile`
21. 双端骨架（web / xhs 双 entry，casual 档）

## 8. 开发前确认状态（2026-09-08 全部裁决）

M1–M4 已裁决（见第 3 节划线条目）：
- **M1**：A 制茶核心流程 Standard ≈ 3 分钟 / Casual ≈ 100 秒；B 第一日完整体验首次 ≈ 8–12 分钟。"3 分钟"仅指标 A，对外不得宣传"3 分钟玩完第一日"。**补充说明：8–12 分钟是产品目标时长，非硬性限制。** 小红书端制茶体验目标约 90–100 秒（与 Casual 100 秒统一口径，以实际测试为准），不为压到 90 秒而删减 P0 核心玩法。
- **M2**：取消"大红袍熟练度 ≥30 解锁"作为 P0 硬门槛；大红袍不作高级等级茶，改为可配置 `unlockCondition: 'exploration' | 'motherTree' | 'story'` 的内容解锁，具体触发在第一日脚本确定，不得形成等级暗示。
- **M3（C8）**：老陈 = 茶农兼茶馆老板，阿秀 = 采茶人，5 人结构不变；不新增 NPC、不做好感度。
- **M4**：斗茶伏笔进 MVP，仅 🔒 + 一句 NPC 台词；完整玩法 P2。
