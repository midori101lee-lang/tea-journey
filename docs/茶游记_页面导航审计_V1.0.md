## 一、每个场景逐条审计（20 项）

### 1. 首页 / 开场（intro · OpeningScene）
- **上一级**：无（启动根场景，`scene` 初始 `'intro'`；`reset()` 也回到 intro）
- **进入方式**：启动即进入
- **可点击区**：`走进去`(enter)→`继续`链条；`点点头/笑着四处看看`(hi 选项)；`端起盖碗，喝一口`(交互)；`清冽/醇厚/说不上来`(know 选项)；`去做茶`(invite)→`finish()`→`onDone()`→**go('garden')**
- **完成默认进入**：garden（茶园）
- **返回**：无（开场无返回按钮）
- **无出口页?**：否（线性推进到底必进 garden）
- **不知下一步?**：🟢 按钮文案即行为，引导清晰
- **文案不一致?**：否
- **层级跳跃?**：否
- ⚠️ 注：开场把玩家**直接送进 garden**，而非武夷山地图。

### 2. 武夷山地图（map · MapView）★核心枢纽
- **上一级**：任何带「回到武夷山」按钮的场景（teahouse / workshop / journal / market）；也是 WebApp 末行未知 scene 的兜底
- **进入方式**：上述场景 `go('map')`
- **可点击区**：
  - `老陈的茶馆` → go('teahouse')
  - `茶园` → go('garden')
  - `制茶坊` → go('workshop')
  - `茶桌` → go('teatable')
  - `九龙窠母树` → go('mothertree')
  - `茶集市`（锁定则 `disabled`）→ 三茶未做齐时禁用；做齐后 → go('market')
  - `📚 我的茶游记` → go('journal')
- **完成默认进入**：无（地图是选点中枢，不自动跳）
- **返回**：无（地图即中枢，无"上一级"概念）
- **无出口?**：否
- **不知下一步?**：🟢 清晰
- **文案不一致?**：market 锁定文案"三种茶都亲手做过，才会开市"与 `isMarketUnlocked` 实际一致
- **层级跳跃?**：否
- ⚠️ 注：**新存档首次见到地图，是在做完一锅茶之后**（经 result→journal→map 或 teatable→*→map）。开场不经过地图。

### 3. 老陈茶馆（teahouse）
- **上一级**：map（点茶馆）；teatable（回茶馆听闲话）；mothertree（回茶馆）
- **进入方式**：go('teahouse')
- **可点击区**：
  - 老陈对话`继续`×N（NpcDialog 推进 laochen）→ 末句→`onDone`→`reveal('laochen')`
  - 若 `lingguReady`（已 tea_made 且未 heard_about_hangzhou）：林姑娘对话`继续`→`reveal('linggu')`
  - 末态`回到武夷山` → go('map')
- **完成默认进入**：显示「回到武夷山」按钮，不自动跳
- **返回**：`回到武夷山`→map
- **无出口?**：否（对话结束后必出现回地图按钮）
- **不知下一步?**：🟢
- **文案不一致?**：否
- **层级跳跃?**：否
- ⚠️ 注：开场已 `meetNpc('laochen')`，故首访茶馆走 **repeat** 对话；`laochen_market_hint`（三茶做完）、`laochen_teahouse_pro`（老练）为条件对话。林姑娘仅在"已做过茶且未听过杭州"时出现。

### 4. 阿秀茶园（garden）
- **上一级**：intro（开场直接）；map（点茶园）；result（回到茶园/换一种茶）；workshop（去茶园）
- **进入方式**：go('garden')
- **可点击区**：
  - 阿秀对话`继续`×N → `reveal('axiu')`
  - 选茶三按钮（肉桂/水仙/大红袍，未解锁则 `disabled`）→ `startMaking` → making
- **完成默认进入**：选茶后 → making
- **返回**：⚠️ **无"返回地图"按钮！** 离开 garden 的唯一方式是选一种茶进入 making
- **无出口?**：否（前方有出口，但无后退出口）
- **不知下一步?**：🟡 新玩家从开场被丢进 garden，没有"先去茶馆/地图逛逛"的退路，只能被迫选茶
- **文案不一致?**：否
- **层级跳跃?**：否
- ⚠️ 注：这是导航上**唯一"只进不退"的场景**。

### 5. 采茶小游戏（PickingStep · making 第 1 步，非独立场景）
- **上一级**：making（step==='picking'）
- **进入方式**：making 自动渲染
- **可点击区**：
  - 引导`嗯`/`好，我挑挑看` → 进入 pick 阶段
  - 茶梢（拖拽，按住往下一带）→ harvest（交互）
  - `收工，去制茶`（result 阶段）→ `onDone(picking)` → MakingFlow.handle → 进入 daoqing
- **完成默认进入**：daoqing（第 2 步）
- **返回**：无（制茶流程内无返回）
- **无出口?**：否（采满 8 篓自动进 result 阶段）
- **不知下一步?**：🟢 提示"按住茶梢，往下一带，就摘下来了"清晰
- **层级跳跃?**：否

### 6. 制茶坊（workshop）
- **上一级**：map（点制茶坊）
- **进入方式**：go('workshop')
- **可点击区**：
  - 岩伯对话`继续`×2 → `reveal('yanbo')`
  - `去茶园` → go('garden')
  - `回到武夷山` → go('map')
- **完成默认进入**：显示两按钮，不自动跳
- **返回**：`回到武夷山`→map
- **无出口?**：否
- **不知下一步?**：🟡 制茶坊本身**不启动制茶**；实际制茶由 garden→选茶→making 触发。提示"先去茶园采好茶青，再来这儿做"——但"做"发生在通用 making 场景，workshop 只是一段岩伯旁白
- **文案不一致?**：🟡 workshop 名为"制茶坊"，制茶五步却在通用 making 场景；岩伯的`做青观察`/`焙火观察`条件对话（依赖 `phase` 标志）**因 `phase` 标志从未被写入，永不触发 → 两条死对话**
- **层级跳跃?**：否

### 7. 倒青（DaoqingStep · making 第 2 步）
- **上一级**：making（picking 完成）
- **可点击区**：`晒`/`晾`切换；`收青`（finish）→ onDone → chao-rou
- **完成默认进入**：chao-rou
- **返回**：无
- **不知下一步?**：🟢 "晒一晒，再晾一晾。叶子要软，青气要退"清晰
- **层级跳跃?**：否

### 8. 做青（ZuoqingStep · making 第 3 步）
- **上一级**：making（daoqing 完成）
- **可点击区**：`按住摇青`（observe/decide）；`再摇一轮`；`就到这儿`（finish）→ onDone → chao-rou
- **完成默认进入**：chao-rou
- **返回**：无
- **不知下一步?**：🟢 "摇够了就收，没有标准答案"清楚
- **层级跳跃?**：否

### 9. 炒揉（ChaoRouStep · making 第 4 步）
- **上一级**：making（zuoqing 完成）
- **可点击区**：锅上按住升温（fire）；`起锅`；趁热揉捻区按住移动（roll）；`进入复炒复揉`/`揉好了`（nextRound→done）→ onDone → roasting
- **完成默认进入**：roasting（第 5 步）
- **返回**：无
- **不知下一步?**：🟢
- **层级跳跃?**：否

### 10. 焙火（RoastingStep · making 第 5 步）
- **上一级**：making（chao-rou 完成）
- **可点击区**：指针区点击 / `落火`（锁定火候，共 taps=5 次）→ 末次 finish → onDone → `finishMaking` → result
- **完成默认进入**：result
- **返回**：无
- **不知下一步?**：🟢 "看准了点一下锁定火候"清楚
- **层级跳跃?**：否

### 11. 制茶结果（result）
- **上一级**：making（焙火完成 → finishMaking）
- **可点击区**：
  - `带去茶桌泡一杯` → go('brew')
  - `再做一锅` → `startMaking(tea.id)` → making
  - `看看茶游记` → go('journal')
  - `回到茶园/换一种茶` → go('garden')
- **完成默认进入**：显示按钮，不自动跳
- **返回**：多出口
- **无出口?**：否
- **不知下一步?**：🟢
- **文案不一致?**：否
- **层级跳跃?**：🟡 **泡茶一次性**：`brew` 依赖 `lastResult`（刚做完时置位）。一旦离开 result 再回来（如 result→garden→选茶→startMaking 会清空 lastResult），之前那锅茶无法再泡。即"泡一杯"只能 result 后立即进行，从 inventory/journal **无法重新进入 brew**

### 12. 茶篓 / 茶叶状态（inventory）
- **不是独立页面**。茶叶状态嵌入：ResultView（"🎒 已收入茶篓"）、JournalView（"做过的茶"列表）、MarketView（可卖列表）
- **可点击区**：仅 MarketView 内 `卖` / `看看这茶怎么样`
- **返回**：无
- **无出口?**：否（嵌入他页）
- ⚠️ 注：**inventory 无独立访问入口**，只能经 journal/market 间接展示；无"查看茶篓"页

### 13. 茶桌 / 周伯（teatable）
- **上一级**：brew（finishBrewing）；map（点茶桌）
- **进入方式**：go('teatable') / finishBrewing
- **可点击区**：
  - 周伯对话`继续` → `reveal('zhoubo')` + `setFlag('tea_made')`
  - `去九龙窠` → go('mothertree')
  - `回茶馆听闲话` → go('teahouse')
  - `看茶游记` → go('journal')
- **完成默认进入**：显示按钮，不自动跳
- **返回**：三出口
- **无出口?**：否
- **不知下一步?**：🟢
- ⚠️ 注：首访走 `zhoubo_teatable_first`；之后再访走 `zhoubo_review`（conditional tea_made）

### 14. 泡茶（brew）
- **上一级**：result（带去茶桌泡一杯）
- **进入方式**：go('brew')（需 lastResult）
- **可点击区**：7 步各 `继续`/`好了`/`出汤`/`闻香`/`收杯`（拖拽交互+按钮）→ TastePhase `收杯` → `finishBrewing` → teatable
- **完成默认进入**：teatable
- **返回**：无（brew 内无中途退出/返回地图）
- **无出口?**：否
- **不知下一步?**：🟢 每步 header+tip 清楚
- **层级跳跃?**：否
- ⚠️ 注：brew 不可从地图/库存重新进入，只能 result 后立即进入（见 #11）

### 15. 品茶结果
- **代码中无独立"品茶结果"场景**。品饮是 brew 第 7 步 TastePhase，完成后 → teatable（周伯点评 + lastBrew）。
- 即"品茶结果"= teatable 场景，不独立成页。

### 16. 九龙窠（mothertree）
- **上一级**：teatable（去九龙窠）；map（点九龙窠母树）
- **进入方式**：go('mothertree')
- **可点击区**：
  - 岩伯对话`继续`×2 → `reveal('mt')`（sets saw_mother_tree，unlocksComic mothertree）
  - `回茶馆` → go('teahouse')
  - `看茶游记` → go('journal')
- **完成默认进入**：显示按钮，不自动跳
- **返回**：回茶馆 / 看茶游记
- **无出口?**：否
- **不知下一步?**：🟢
- **文案不一致?**：否（母树立绘为岩伯，符合最新定位）
- ⚠️ 注：母树对话仅 `first` 类型、无 `repeat` → 之后再访 mothertree 会**重播整段** yanbo_mothertree（无害，flag 幂等），属轻微重复

### 17. 母树漫画 / 知识卡（comic）
- **上一级**：journal（点已解锁漫画）→ go('comic', {comicId})
- **进入方式**：go('comic')
- **可点击区**：`收进茶游记` → go('journal')
- **返回**：journal
- **无出口?**：否
- **不知下一步?**：🟢
- ⚠️ 注：母树漫画 `comic_mother_tree` 由 mothertree 对话 `unlocksComic` 解锁；HEIC 实拍图仅作 knowledge 素材，不进此漫画

### 18. 图鉴（journal）
- **上一级**：map 的`📚 我的茶游记`；teahouse/teatable/mothertree/result 的`看茶游记`
- **可点击区**：漫画条目（点击）→ go('comic')；`回到武夷山` → go('map')
- **返回**：map
- **无出口?**：否
- **不知下一步?**：🟢

### 19. 茶集市（market · 当前默认锁定）
- **上一级**：map（点茶集市，仅三茶做完后解锁）
- **进入方式**：go('market')（仅 isMarketUnlocked）
- **可点击区**：
  - 小满对话`继续` → `setTalked(true)`
  - `卖` → `sell(stack)` 得茶钱
  - `看看这茶怎么样` → 轻量辨茶评价（evaluateTea）
  - `回到武夷山` → go('map')
- **完成默认进入**：显示按钮，不自动跳
- **返回**：map
- **无出口?**：否（锁定态在地图 `disabled` 表现）
- **不知下一步?**：🟢（解锁后清晰）
- ⚠️ 注：解锁条件与 `madeTeas`（三种茶各做过一次）一致；小满对话无 `repeat` → 每次进入重播首段（无害）

## 四、问题分级

### 🟢 导航清晰（无需改动）
intro、map、teahouse、result、teatable、mothertree、comic、journal，以及 making 五步 + brew 的**步骤内**推进。所有活跃场景均有明确前进出口，无死路。

### 🟡 可以使用但需要优化
1. **garden 无"返回地图"按钮**（只进不退）——新玩家从开场被直接丢进茶园，想先逛茶馆/地图只能被迫选茶进入 making。
2. **workshop 与 making 脱节**——"制茶坊"名义上是制茶发生地，实际制茶五步在通用 `making` 场景；workshop 仅岩伯旁白。
3. **workshop 两条死对话**——`yanbo_zuoqing` / `yanbo_roasting` 依赖 `phase` 标志，但代码中无任何 `setFlag('phase', …)` 写入点 → **永不触发**。
4. **泡茶一次性**——`brew` 只能在 result 后立即进入（依赖 lastResult）；离开 result 后再做茶会清空 lastResult，已做之茶从 inventory/journal **无法重新泡**。
5. **母树 / 小满无 repeat 对话**——只有 `first` 类型 → 每次重访重播整段首对话（无害，但重复）。
6. **开场直接进茶园，地图为"后期发现"**——与"进入武夷山→地图选点"的常见心智不同（设计取舍，非 bug）。
7. **inventory 无独立入口**——茶篓状态只嵌入 journal/market，无"查看茶篓"页。
8. **代码残留·`pick-tea` 死分支**——WebApp 第 74 行定义了 `if (scene==='pick-tea')` 渲染 TeaSelect，但 Web 端**无任何 `go('pick-tea')`**，仅在 XHS 使用，属 Web 死分支。
9. **代码残留·`clue` 死场景**——`Scene` 联合类型含 `'clue'`，但无渲染分支、无 `go('clue')`，永不可达（线索改在 journal 列表展示）。

### 🔴 玩家很可能迷路 / 不知道下一步
**经逐场景核查，当前 Web 端没有真正的 🔴 级导航断点。** 所有活跃场景都有明确出口，不存在"点了没反应 / 卡死 / 无路可走"的硬伤。
- 最靠近体验风险的是 **#1 garden 只进不退**（但前方必通，不算真迷路）与 **#4 泡茶一次性**（一次性设计，非断点）。
- 若一定要定位"最可能让人困惑"的点：**新玩家首轮看不到地图、且茶园无退路**，可能误以为"只能做茶"；以及离开制茶结果页后想泡茶却找不到入口。

## 五、文档 / 心智 vs 代码 的实际差异（重点标出）

| 文档/常见心智 | 代码实际 | 是否一致 |
|---|---|---|
| 进入武夷山 → 地图选地点 | 开场动画 → **直接茶园**；地图是做完一锅后经 journal/各场景"回到武夷山"才首次出现 | ❌ 不一致 |
| 制茶坊（workshop）是制茶发生地 | 制茶五步在通用 `making` 场景；workshop 仅岩伯旁白 + 两条死条件对话 | ❌ 不一致 |
| "品茶结果"是独立环节 | 品饮 = brew 第 7 步 TastePhase，无独立页；结果体现在 teatable 周伯点评 | ❌ 不一致 |
| 有独立"茶篓/背包"页 | 无独立 inventory 页，茶叶状态嵌入 journal/market | ❌ 不一致 |
| 岩伯在制茶坊"做青/焙火时给提示" | `phase` 标志无写入点 → 该提示永不出现 | ❌ 不一致 |
| 茶集市解锁 = 三茶各做一遍 | 代码一致（madeTeas + isMarketUnlocked） | ✅ 一致 |
| 大红袍由母树内容触发解锁 | 代码一致（saw_mother_tree） | ✅ 一致 |

## 六、XHS 端导航差异（简记）
XHS（`XhsApp.tsx`）是**极简线性流**，不接入地图/对话链/九龙窠/茶集市/图鉴：
- `intro/map/teahouse` 合并为首屏（"开始制茶"→garden）
- `garden/pick-tea` → TeaSelect → making → result → brew → teatable（分享卡：再做一锅 / 换一种茶）
- 无 mothertree、workshop、market、journal、comic 路由
- 仅 `TeaSelect` 经 `garden` 或 `pick-tea` 进入（即 XHS 才用到 `pick-tea` 分支）

## 七、给产品负责人的一句话

> 当前 Web 端导航**没有死路**，但"茶园只进不退 + 泡茶一次性 + 制茶坊与真实制茶脱节 + 两条岩伯死对话"是四处理应优先顺手修掉的体验缝隙；其中只有"制茶坊死对话"和"茶园缺返回"属于低成本高收益的真实缺口，其余多为设计取舍而非故障。
