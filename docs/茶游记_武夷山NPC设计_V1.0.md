# 《茶游记》武夷山第一章 · NPC 设计 V1.0

版本：V1.0（依据 2026-09-08 用户裁决，取代 V0.3 §12 中与之冲突的 NPC 表）
性质：NPC 设计基线文档。**本轮只定设计，不写代码。**
原则：不新增 NPC、不做复杂好感度系统、每个 NPC 有不可替代的核心功能、知识不重复讲述。

---

## 1. 总链条：五个人 = 五段认识

> 这是本章 NPC 系统的骨架，一切台词与触发都为它服务。

```
老陈  ：认识茶山        「这里的人怎么喝茶、怎么生活？」
  ↓
阿秀  ：认识茶叶        「茶是怎么从山上摘下来的？」
  ↓
岩伯  ：认识制茶        「这片叶子到底该怎么做？」
  ↓
周伯  ：认识喝茶        「这茶做出来到底好不好喝？」
  ↓
林姑娘：认识下一座茶山   「别的地方的茶又是什么样？」
```

每人回答**一个**问题。玩家的问题会沿着这条链自然传递——上一个 NPC 的结尾，就是下一个 NPC 的开场。

## 2. 五人卡片

### 2.1 老陈 ｜ 茶农兼茶馆老板

| 项 | 内容 |
|---|---|
| 在哪认识 | 茶馆（玩家进入武夷山的第一个地点） |
| 核心职能 | 生活、人情、茶山旧闻、茶馆、收茶/交易、开场引导 |
| 核心关键词 | 生活 / 闲谈 / 生意 / 旧闻 |
| 他回答什么 | 「这里的人怎么喝茶、怎么生活？」 |
| **不负责** | **不负责采茶教学，不负责制茶教学** |
| 性格 | 热情、见多识广、会做生意但不油 |
| 特殊地位 | ① 玩家认识武夷山的第一个当地人；② **贯穿式 NPC**（见第 4 节）；③ **母树内容唯一归属** |

**台词基调**
```
「第一次来武夷山？先喝一杯，喝了再说。」
「岩茶就这样，头一口不讨好人。」
「光喝有什么意思？要不要自己做一锅？」
「这茶留我这儿？三十八，怎么样。」
「你要问真正那几棵？早不让采了。」      ← 母树
「做茶急不得。坐会儿吧，茶又不会跑。」
```

### 2.2 阿秀 ｜ 采茶人

| 项 | 内容 |
|---|---|
| 在哪认识 | 茶园 |
| 核心职能 | 茶园、采茶、茶青、茶季、劳作感 |
| 核心关键词 | 土地 / 茶青 / 茶季 / 劳作 |
| 她回答什么 | 「茶是怎么从山上摘下来的？」 |
| **不负责** | **不负责母树故事、不承担茶文化百科功能** |
| 性格 | 爽快、直接、利落、有点累 |
| 特殊地位 | 采茶玩法的主要 NPC；让玩家感受到**采茶是劳动** |

**台词基调**
```
「别光顾着看风景，茶青要赶时间。」
「太嫩的别摘。」
「这个可以，开面了。」
「你动作还挺快。」
「这几天都住在厂里，茶青在楼上等着呢。」
```

### 2.3 岩伯 ｜ 老制茶师

| 项 | 内容 |
|---|---|
| 在哪认识 | 制茶坊 |
| 核心职能 | 制茶坊、实时观察、制茶评价 |
| 核心关键词 | 手艺 / 状态 / 火候 |
| 他回答什么 | 「这片叶子到底该怎么做？」 |
| **不负责** | 不讲工艺历史，不做工序科普 |
| 性格 | 话少、嘴硬、经验丰富 |
| **铁律** | **只描述状态，不直接告诉玩家答案**（"看青做青"的人格化） |

**台词基调（按实时表现插话）**
```
优秀：「稳。」／「嗯，走水了。」／「火走得稳。」
普通：「还能喝。」／「有点急，但还救得回来。」
失败：「急了。」／「糊了。」／「摇得太狠了，叶子有些伤。」
多次成功后：「有点样子了。」
```

### 2.4 周伯 ｜ 老茶客

| 项 | 内容 |
|---|---|
| 在哪认识 | 茶桌 |
| 核心职能 | 泡茶、品评、幽默反馈 |
| 核心关键词 | 味道 / 点评 / 嘴毒 |
| 他回答什么 | 「这茶做出来到底好不好喝？」 |
| **不负责** | 不讲工艺、不讲历史；只对"喝到嘴里的东西"发言 |
| 性格 | 不端着，用普通人的语言，毒但准 |
| 特殊地位 | 让玩家感受到「自己做出来的茶怎么样」；也是**泡茶玩法**的主要 NPC |

**台词基调**
```
「香是香，就是火有点重。」
「这个汤舒服。」
「肉桂就是要有点劲。」
「大红袍嘛，得喝过几种才知道。」
「懂不懂茶不重要，别把好茶泡坏了。」
```

### 2.5 林姑娘 ｜ 游历茶客

| 项 | 内容 |
|---|---|
| 在哪认识 | 茶馆 / 茶桌 |
| 核心职能 | 外地视角、茶区比较、下一站线索 |
| 核心关键词 | 远方 / 比较 / 下一座茶山 |
| 她回答什么 | 「别的地方的茶又是什么样？」 |
| **不负责** | 不做武夷山知识讲解（她是外人，讲武夷山反而出戏） |
| 性格 | 好奇、爱聊、没有优越感 |
| 特殊地位 | **下一座茶山线索的唯一来源**；把探索欲从武夷山延伸到杭州 |

**台词基调**
```
「老板，你这茶……和我老家的不是一个路子。」
「我们那边做茶，不摇青，是炒的。」
「有机会，你去看看？」
```

## 3. 知识所有权矩阵（防重复讲述）

> 规则：**每个知识点只有一个"主讲述人"**；其他 NPC 最多做一句情绪回应，不做解释。

| 知识点 | 主讲述人 | 其他人允许的回应 | 禁止 |
|---|---|---|---|
| 开面采 / 茶青判断 | **阿秀** | 老陈收茶时可说"这青不错" | 老陈、岩伯讲采摘标准 |
| 茶季 / 劳作 | **阿秀** | — | 任何人科普茶叶生产流程 |
| 做青状态（走水/红边） | **岩伯** | — | 阿秀、老陈解释做青原理 |
| 火候 / 焙火 | **岩伯** | 周伯喝茶时说"火有点重" | 老陈讲焙火工艺 |
| 三茶的"喝感"区别 | **周伯** | 林姑娘可比较"和我们那不一样" | 任何人讲品种谱系（待考证项） |
| 三茶的"买卖与生活" | **老陈** | — | 把卖点上升为茶学事实 |
| 母树 / 茶山旧闻 | **老陈** | — | **任何人**（含阿秀）讲母树；绝无可采入口 |
| 喊山（P1） | **老陈**（"来了。""喊山。"） | 阿秀一句"每年都这样" | 解释喊山历史沿革 |
| 泡茶基本法 | **周伯** | — | 老陈、岩伯教泡茶 |
| 下一座茶山线索 | **林姑娘** | 老陈只在玩家拿到线索后说"路我给你问好了" | 老陈、周伯直接给线索 |
| 「岩骨花香」这个词 | **周伯**（喝到好茶时脱口而出） | 老陈可在招牌/闲谈中带过 | 任何人解释这个词的定义 |

**冲突自检结论**
- ✅ 老陈与阿秀职能重叠：**已消除**——老陈不管采茶教学，阿秀不管母树与百科
- ✅ 三茶区别被多人讲的风险：**已规则化**——老陈讲买卖、周伯讲喝感、林姑娘讲比较，三者内容互斥
- ✅ 线索唯一来源 = 林姑娘；老陈只做拿到线索之后的"送行"

## 4. 老陈的贯穿式路线（七次相遇）

> 不是"母树 → 出现一个 NPC → 讲完 → 消失"。老陈是玩家在武夷山的**常数**。

| # | 时机 | 地点 | 老陈做什么 |
|---|---|---|---|
| 1 | 首次进入 | 茶馆 | 递茶、开场、认识这座山 |
| 2 | 开场结束 | 茶馆 | 「要不要自己做一锅？」→ 指向茶园 |
| 3 | 首次制茶中途 | 制茶坊（路过） | 送水/看火，一句闲话就走（不指导） |
| 4 | 首日收茶 | 茶馆 | 收茶/交易，第一笔茶钱 |
| 5 | 闲谈 2 次后 | 茶馆 | **母树**：「早不让采了」→ 解锁茶山旧闻 + 漫画 |
| 6 | 线索到手后 | 茶馆 | 「去杭州的路，我给你问好了。」 |
| 7 | 之后每次回访 | 茶馆 | 台词随**熟练度档位**变化（见第 6 节） |

> 喊山（P1）挂在第 6/7 次之间的茶园路过事件上，仍由老陈说「来了。喊山。」

## 5. 对话数据结构检查（对照现有 `core/types.ts`，本轮不改代码）

| 现有结构 | 是否够用 | 需增补 |
|---|---|---|
| `Npc { id, name, role, regionId, personality, avatar, dialogues{first,repeat,conditional} }` | 基本够用 | ① `role` 更新为"茶农兼茶馆老板"；② 增加 `locationId`（首次出现地点）；③ `dialogues.repeat` 需支持**按熟练度档位变体** |
| `DialogueLine { id, who, text, mood, giveClueId, setFlag }` | ✅ 够用 | 无需改；线索走 `giveClueId`，只有林姑娘的台词携带 |
| `NpcMemory { met, visitCount, lastDialogueId, impression }` | ✅ 够用 | **不做好感度系统**：`impression` 仅作为台词开关（如 老陈熟客版/生客版），永不显示 |
| `UnlockCondition` | ✅ 够用 | 老陈台词档位用 `{ type:'proficiency' }` 求值，**按档位名（初学/入门/熟手/老练）而非数字** |

**结论：数据结构无需结构性改动，只补两个字段与一套台词数据。**

## 6. 台词随熟练度变化（以老陈为例，四档）

| 档位 | 收茶时 | 闲谈时 |
|---|---|---|
| 初学 | 「第一次做茶？卖我，我按良心价。」 | 「慢慢来，山又不会跑。」 |
| 入门 | 「嗯，比上一锅像样。」 | 「你倒是来得勤。」 |
| 熟手 | 「你这茶，我给你摆柜台上卖。」 | 「后生可畏啊。」 |
| 老练 | 「老主顾都问你名字了。」 | 「哪天我这店，交给你看两天？」 |

> 原则：熟练度变化体现在**语气与待遇**，不是数值。岩伯的对应变化是"话越来越少"（初学多提醒，老练几乎沉默）。

## 8. 红线（与资料库 §32/§30 对齐）

1. 禁止百科腔：「武夷岩茶文化源远流长……」❌
2. 禁止旅游宣传腔：「这里山清水秀，是著名旅游胜地」❌ → 「今天茶青还没送下来」✓
3. 岩伯永不指导，只描述所见
4. 老陈永不教学（采茶/制茶），只生活、生意、旧闻
5. 母树只从老陈口中说出，且必须含「早不让采了」与「现在喝到的大红袍跟它们是两回事」的意涵
6. 林姑娘不做武夷山知识讲解
7. 所有可能的营销话术（"水仙适合女性""大师茶"）不得作为知识；"大师茶"段子属 P2 景区茶商素材
