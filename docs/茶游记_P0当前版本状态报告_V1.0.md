## 1. 当前版本一句话总结

《茶游记》武夷山第一日主线（茶馆→茶园→采茶→制茶坊→制茶→茶桌品茶→九龙窠母树）**从代码到渲染已端到端贯通、可完整试玩**；茶集市最小可玩版（三茶制作解锁 + 小满卖茶/辨茶）与九龙窠母树（岩伯出场）已在本精修接入；「林姑娘/随机茶商」偶遇、L2/L3 茶差异、多茶区仍为**预留未实现**。（初版误判"大红袍需熟练度≥30 解锁"——实际由 `saw_mother_tree` 内容触发，与熟练度无关，详见第 19 节修订说明。）

## 3. 当前真实玩家流程（代码可走通）

```
首页(开始)
  ↓
OpeningScene（武夷山 establishing → 老陈茶馆 → 喝茶认识肉桂 → 受邀做茶）
  ↓
MapView（武夷山地图）
  ├─ 老陈茶馆 ──→ 老陈对话(teahouse) → 循环/了解肉桂
  ├─ 阿秀茶园 ──→ 阿秀对话(garden) → 采茶 PickingStep(茶梢开面采+竹篮)
  │                 └─ 采完 → 提示去制茶坊
  ├─ 制茶坊   ──→ 岩伯对话(workshop) → 制茶 MakingFlow
  │                倒青→做青(摇青+静置3-4轮)→炒揉(双炒双揉)→焙火(动态指针)
  │                └─→ ResultView(品质四档+茶钱) → 成茶入茶篓
  ├─ (做完茶) 茶桌 ──→ 周伯品茶 BrewingFlow(6步拖拽) → 品茶对话
  ├─ 九龙窠/母树 ──→ 岩伯对话(mothertree) → 母树漫画 ComicView → 杭州线索
  └─ 图鉴(随时) ──→ JournalView（知识卡/漫画）
```

**流程断点（明确标注）：**
- 【流程断点-A（初版误判·已更正）】初版称"大红袍需熟练度≥30 解锁"——**错误**。代码实际：`unlockCondition.type==='motherTree'`，由 `saw_mother_tree` 标记（完成九龙窠母树对话）解锁，与熟练度数字无关。首轮走通主线即可解锁大红袍，属预期行为非 bug。
- 【流程断点-B（初版·已解决）】初版称茶集市整块锁定——本精修已实现：肉桂+水仙+大红袍各亲手制作过一次即解锁 `market`，小满进场景、可卖茶/轻量辨茶。
- 【流程断点-C】林姑娘（偶遇）当前主线未稳定编排触发：九龙窠交的是「老陈+杭州线索」，林姑娘 herself 未在武夷山主线条触发，仅 `linggu` 场景与对话数据存在 → 【已实现/未接入流程】。

## 8. 制茶状态

**【已实现/可玩】** 武夷岩茶五步全实现（`MakingFlow` + 五个 step）：
1. 采茶 ✅（见上）
2. 倒青/萎凋 ✅ 两晒两晾（`DaoqingStep`）
3. 做青 ✅ 摇青→静置→再摇青 3–4 轮，观察叶缘朱砂红（`ZuoqingStep`，有判断）

- 失败：产生废品/低品质成茶，消耗本轮鲜叶，不扣茶钱。
- 品质：四档 fail/normal/good/fine，**已取消复杂多维数字评分**（`scoring.ts` 仅汇总步骤评价→档位）。
- 天况：无随机天气（P2 明确不做完整天气）。
- 三茶差异：**仅 L1 参数差异**（火功倾向/香气取向/采摘要求），`teas.ts` 已配；**L2/L3 玩法差异未实现**（只有设计，无代码）。

## 19. 文档修订说明（V1.0 → 武夷山 MVP 精修后）

本报告 V1.0（只读审计）存在一处事实误判与两处已随开发解决的状态标注，于「武夷山 MVP 精修 V1.0」任务中更正，记录如下：

1. **大红袍解锁误判（重要）**：V1.0 称"大红袍需熟练度≥30 解锁，首轮做不了"。经代码核查，实际解锁条件为 `unlockCondition.type==='motherTree'`，由完成九龙窠母树对话置位的 `saw_mother_tree` 标记触发，**与熟练度数字无关**。首轮走通主线（含九龙窠）即可解锁大红袍，符合 V0.3「大红袍不作高级等级茶、由游历内容触发」的设计意图，非 bug。本版全文已删除该误判，熟练度行注明"只影响制茶表现/容错与部分对话"。
2. **九龙窠母树立绘错位（已解决）**：V1.0 称母树场景叠加老陈立绘属设计错位。本精修将母树对话 `npcId` 由 `laochen` 改为 `yanbo`，现由岩伯在母树前出场，符合"岩伯=九龙窠/母树负责人"的分工。
3. **茶集市/小满（已解决）**：V1.0 称茶集市整块锁定、小满未进场景。本精修新增 `madeTeas` 历史记录（三茶各亲手制作一次解锁 `market`）、`MarketView`（小满对话+卖茶得茶钱+轻量辨茶原型）、`market.webp` 背景，market 地点 `npcIds` 加 `xiaoman`。
