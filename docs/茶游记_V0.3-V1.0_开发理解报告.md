## 1. 我理解的产品

### 《茶游记》是什么
一场可以玩的中国茶山游历。不是茶百科、不是制茶模拟器、不是旅游宣传册、不是 RPG 数值养成。
玩家从一间茶馆开始，认识人、采茶、做茶、焙火、泡茶、听故事，然后在某句闲谈里听说——原来那边也产茶。

### 玩家是谁
一名进入中国茶世界的**茶山游历者 / 茶客**。不是学生（不考试），不是茶艺师（不背参数），是一个在路上、对茶好奇的普通人。

### 玩家为什么愿意玩
长期动力的排序是 **探索欲 > 收集欲 > 成长欲 > 知识学习**。
核心驱动不是"我要学会茶"，而是——
> 「诶？杭州的茶又是什么样？」

下一座茶山**不是任务奖励**，是好奇心兑现：线索来自闲谈，且由玩家主动"出发"。

### 核心游戏循环
```
进入茶区 → 认识当地人 → 采茶 → 制茶 → 获得茶叶
   → 茶叶进入茶篓 → 泡茶 / 赠送 / 卖掉 / NPC 点评
   → 熟练度提升 → 听到一句闲话（线索）→ 想去下一座山
```

### 第一章为什么是武夷山
- 武夷岩茶（大红袍）制作技艺是国家级非遗，工艺辨识度极高
- 有"岩骨花香"这种一句话可记的地域性格
- 有母树传说、喊山、斗茶等天然故事素材
- 有肉桂/水仙/大红袍三个"普通玩家也能分辨"的主角
- 采用「先做一座山，再做整个中国」的策略：MVP 只做武夷山，把地图留给茶区 ≥3 时

### 第一章核心玩法
五个可玩节点：**采茶（开面采判断）→ 倒青（两晒两晾）→ 做青（摇青+静置，叶缘转红）→ 炒揉（双炒双揉，一个 step 两轮）→ 焙火（动态指针）**；
之后是 **泡茶（出汤时机判断）** 与 **结果 → 茶篓 → NPC 点评**。

### 制茶的定位
**制茶是玩家进入茶世界的第一把钥匙，不是终点。**
做完茶必须流向"泡一杯自己做的茶、被人点评、听来一句闲话"，否则玩家会问「我为什么要做茶？」

### 游戏与真实茶文化的关系
> **真实世界决定规则，游戏机制负责降低复杂度。**

- 现实提供骨架与因果，游戏压缩操作次数，但**不能破坏因果**
- 不能为了"真实"不断增加工序（拣剔、扬簸、凉索一律旁白带过）
- 不能把游戏参数包装成茶学事实
- 判断标准只有一个：玩家最终记住的应该是「我刚刚在武夷山，亲手做了一锅茶」

## 4. 真实性边界

### A. 游戏必须尊重的真实规则（不可违背）
1. 武夷岩茶**不是采下来就能喝**，必须经过复杂工艺（资料库 §2.2）
2. 传统流程骨架：采摘 → 倒青/萎凋 → 做青（晾青⇌摇青）→ 初炒 → 初揉 → 复炒 → 复揉 → 初焙 → 扬簸 → 凉索 → 拣剔 → 复焙 → 吃火 → 团包 → 补火 → 装箱（DB35/T 2157-2023，S 级）
3. 非遗关键语汇必须可追溯：**复式萎凋 / 看青做青 / 看天做青 / 走水返阳 / 双炒双揉 / 低温久烘**（A 级）
4. **开面采**：不是越嫩越好，也不是越老越好（资料库 §4）
5. **做青没有固定程序**：茶青状态与天气不同，做法不同；"每次摇 5 秒满分"是错误设计（资料库 §6.3）
6. **焙火 ≠ 温度越高越好**；绿区不是固定温度答案（资料库 §8/§9.2）
7. 母树大红袍 **≠** 今天市场上"大红袍"的简单来源；母树已停采保护（资料库 §12.2/§24）
8. 大红袍名称来源属**传说体系**，必须标"传说"（资料库 §27）
9. 母树是故事不是资源：不可采、无坐标、无稀有掉落（资料库 §24）
10. 盖碗 / 紫砂壶多次冲泡；盖碗是 MVP 最合适方式（资料库 §20）

### B. 可以进行的合理简化（保留因果即可）
1. 16 道工序压缩为 5 个可玩节点
2. **双炒双揉压成一个 Step、内部两轮**（玩家感知一次，系统保留两轮逻辑）
3. 初焙并入焙火前段；扬簸/凉索/拣剔/团包/装箱 → 结果页一句旁白
4. 做青由"长时间反复"压缩为 3–4 轮；静置可加速
5. 焙火用"动态指针 + 多轮累积"表达"低温久烘"的判断本质
6. 泡茶不要求克数与秒数精度，用视觉与口语表达
7. 熟练度单一不拆分；不显示数字
8. 采茶用"太嫩/合适/太老"判断代替真实采摘标准细节

### C. 可作为游戏表现、但**不能包装成专业事实**
1. 三茶的**游戏参数差异**（做青力度、炒青安全区宽度、焙火绿区中心/宽度、解锁熟练度、基础茶钱）——资料库 §49 明确要求降级为 `teaGameProfile` 之类的**可调游戏参数**，禁止写进知识系统宣称「肉桂现实中一定要重摇青」
2. "张扬派 / 温润派 / 平衡派" —— 游戏化标签，**不是茶学分类**
3. "先闻香 / 喝的是汤 / 喝了才知道" —— 玩家记忆句 / NPC 主观表达
4. NPC 的一切评价性台词（"这锅真不错"）→ `TeaCopy.npcOpinion`
5. "新手喝起来比较容易接受" 类体验描述 → `gameHint`
6. 茶钱数值、出汤秒数、投茶量 → **游戏参数**，不宣称专业标准
7. 喊山的游戏化呈现（鼓声 → 茶发芽啰）→ 文化表现，不作历史考据
8. 牛肉/马肉（牛栏坑/马头岩俗称）→ 可作茶圈俗称与地方消费文化素材，**不得建立"牛栏坑=数值更高"的绝对关系**

### D. 明确禁止出现的表达
| 禁止 | 说明 |
|---|---|
| ❌ 水仙"适合女性" | 营销语言，不可作为事实（资料库 §14/§51.4） |
| ❌ 大红袍 = 肉桂 + 水仙 | 只能说"市场存在拼配大红袍"，不可说"大红袍就是两者拼的"（§51.3） |
| ❌ 牛肉一定优于马肉 | 不得建立固定品质等级（§51.5） |
| ❌ 老丛 = 一定有固定香味 | 丛味/枞味是常见说法，不作绝对规律（§11） |
| ❌ 水仙 = 用水仙花做的茶 | 水仙是茶树品种（§28，可作轻松知识卡） |
| ❌ 把传说写成历史 | 必须标【传说】/「民间流传着这样一个故事」（§27） |
| ❌ 专业审评数字外显 | 香气 86 / 滋味 91 一律不显示（§15.1） |
| ❌ 熟练度数字外显 | 熟练度 37 / +5 熟练度 不显示（§17） |
| ❌ 采摘准确率 92% | 改用"看准了，是开面的"（§4） |
| ❌ 焙火温度固定答案 | "达到 120℃ 才正确"不存在（§9.2） |
| ❌ 唯一正确的投茶量 / 出汤秒数 | 资料有分歧，只用游戏参数（§21/§22） |
| ❌ 母树可采 / 母树掉落 / 母树坐标 | 母树是故事（§24） |
| ❌ 旅游宣传腔 | "山清水秀著名胜地" → "今天茶青还没送下来"（§30） |
| ❌ 百科腔 NPC | "武夷岩茶文化源远流长……"（§32） |
| ❌ 神品等级 | 已取消（决策 Q2） |
| ❌ 失败扣茶钱 | 只消耗鲜叶（决策 Q3） |
