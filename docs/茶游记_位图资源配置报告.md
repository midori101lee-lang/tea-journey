## 6. 工具与格式

- 转换在**本机完成，零外部网络依赖**：
  - NPC/背景：`Pillow 12.3`（managed Python 3.13.12，已验证 `webp` 支持且 RGBA 无损/有损均保透明）。
  - HEIC：macOS 内置 `/usr/bin/sips` 转 JPEG → Pillow 转 WebP（Pillow 自身不能读 HEIC）。
- 未使用 `cwebp`/`webpmux`/`magick`/`ffmpeg`/`sips` 转图以外的工具（环境无）。
- NPC 立绘处理：裁剪透明留白（3% 边距）→ 最长边 ≤1400 → WebP 无损（保透明，锐边无失真）。
- 背景处理：最长边 ≤1600 → WebP 有损 q82（照片类，体积小）。

## 10. 后续微调建议（视试玩）

- 位图立绘为**高瘦全身像**（比例约 1:2.3），figure 位置已按保守值预调（width 40–46、bottom 14–18，单位 %）。实际叠在不同位图背景上时，脚底/头部与背景构图可能需 ±2–4% 微调——属纯视觉校准，不改逻辑。
- 若试玩后觉得某立绘偏大/偏上，直接调 `src/components/scenes/index.ts` 中对应 `figure` 即可。
- 茶集市（P2）启动时，把 `xiaoman`/`laojia` 加进 `regions.ts` 的 `market.npcIds`，并补对话即可点亮，无需重配资源。
