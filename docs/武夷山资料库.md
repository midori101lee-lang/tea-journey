《茶游记》·武夷山第一章
真实性资料库 × 游戏转化规范 V1.0
用途：供《茶游记》开发使用。
本文不是茶学教材，也不是专业制茶模拟器，而是将武夷山真实茶文化转译为游戏内容的开发知识库。
核心原则：
真实世界决定规则，游戏机制负责降低复杂度。
《茶游记》希望让玩家通过“玩”自然认识武夷山，而不是要求玩家背诵茶知识。

0. 项目总原则
0.1 产品定位
《茶游记》是一场可以玩的中国茶山游历。
中国每一座茶山，都有自己的故事。
玩家是一名进入中国茶世界的茶山游历者 / 茶客。
从一间茶馆开始：
进入茶馆
→ 认识当地人
→ 采茶
→ 做茶
→ 焙火
→ 泡茶
→ 喝自己的茶
→ 听当地故事
→ 认识不同茶
→ 获得下一座茶山的线索
制茶是玩家进入茶世界的第一把钥匙。

0.2 不要做成什么
《茶游记》不是：
	•	茶知识考试
	•	茶叶百科
	•	专业制茶模拟器
	•	专业茶叶感官审评软件
	•	旅游宣传册
	•	RPG 数值养成游戏
不要为了“真实”不断增加工序、属性和专业参数。

2. 武夷山与武夷岩茶
2.1 武夷岩茶是什么
武夷岩茶属于乌龙茶，是武夷山地区具有代表性的茶类。
其重要的地域特色通常通过：
岩骨花香
进行概括。
武夷岩茶传统制作技艺是国家级非物质文化遗产项目。
传统制作工序十分复杂，并不是简单的“采摘 → 杀青 → 揉捻 → 干燥”。

2.2 游戏中的基本认知
玩家不需要学习完整工艺流程。
玩家只需要逐渐形成这样的认知：
武夷岩茶不是采下来就能喝。
茶青需要经过：
采摘
↓
倒青 / 萎凋
↓
做青
↓
炒青
↓
揉捻
↓
复炒 / 复揉
↓
焙火
↓
成茶
现实中还有扬簸、凉索、拣剔、复焙、吃火、团包、补火、装箱等复杂步骤。
游戏不需要全部操作。
但不能破坏关键因果关系。

3. 武夷岩茶传统制作工艺
3.1 现实工艺骨架
地方标准 DB35/T 2157-2023《非物质文化遗产 武夷岩茶传统制作技艺》列出的传统流程包括：
采摘 → 倒青（萎凋） → 做青（晾青⇌摇青） → 初炒 → 初揉 → 复炒 → 复揉 → 初焙 → 扬簸 → 凉索 → 拣剔 → 复焙 → 吃火 → 团包 → 补火 → 装箱
国家级非遗资料同时强调：
	•	复式萎凋
	•	看青做青
	•	看天做青
	•	走水返阳
	•	双炒双揉
	•	低温久烘
这些是理解武夷岩茶工艺的关键。

4. 《茶游记》中的五个核心制茶节点
为了让游戏可玩，MVP 将复杂工艺压缩为五个玩家真正需要操作的节点：
① 采茶
↓
② 倒青 / 萎凋
↓
③ 做青
↓
④ 炒青 + 双炒双揉
↓
⑤ 焙火
↓
成茶

4.1 采茶
【现实】
武夷岩茶传统采摘强调开面采。
不是越嫩越好，也不是越老越好。
传统上会根据茶树新梢成熟程度判断采摘时机。
【游戏】
玩家面对不同成熟程度的茶芽/茶梢。
需要判断：
太嫩 / 合适 / 太老
正确判断：
开面采
【游戏反馈】
不要出现：
“采摘准确率 92%”
而使用：
“看准了，是开面的。”
“太嫩了，再等等。”
“这叶子已经有些老了。”
【核心认知】
玩家记住：
武夷岩茶讲究开面采。

5. 倒青 / 萎凋
5.1 【现实】
武夷岩茶传统工艺使用“倒青”这一地方性称谓。
传统工艺中存在复式萎凋，并涉及晾晒、摊放等过程。
核心不是简单“把茶叶晒干”。
而是让鲜叶发生适当的水分变化和状态变化，为后续做青创造条件。

5.2 【游戏】
游戏中压缩为：
铺开 → 观察 → 判断是否收叶
可以通过：
	•	叶片状态
	•	光泽
	•	柔软程度
	•	香气变化
给玩家反馈。
不要要求玩家理解复杂生化过程。
推荐提示
“叶片开始柔软了。”
“青气退了一些。”
“还没到时候，再等等。”

6. 做青——武夷岩茶的核心玩法
6.1 【现实】
做青是武夷岩茶形成品质的重要环节。
传统工艺强调：
看青做青，看天做青。
也就是说：
	•	茶青状态不同，做法不同；
	•	天气条件不同，做法也需要调整；
	•	做青不是固定程序。
传统工艺会经历多次：
摇青 ↔ 静置 / 晾青
过程。
在适当条件下，叶片会出现：
“绿叶红镶边”
等典型视觉变化。

6.2 【游戏】
做青是 MVP 中最重要的制茶小游戏之一。
流程：
观察茶青
↓
摇青
↓
观察
↓
静置
↓
再次摇青
↓
再次观察
↓
……
↓
完成做青
游戏压缩为约 3–4 轮。

6.3 不要把它做成“固定答案”
错误设计：
每次摇青 5 秒就是满分。
正确设计：
根据当前茶青状态判断力度和时机。
这样才符合：
看青做青。

6.4 游戏反馈
优秀：
“叶缘开始泛红，走水走得漂亮。”
“这次摇得稳。”
普通：
“有点急，但还救得回来。”
失败：
“摇得太狠了，叶子有些伤。”

7. 炒青 + 双炒双揉
7.1 【现实】
武夷岩茶传统工艺中存在：
双炒双揉
即：
初炒
↓
初揉
↓
复炒
↓
复揉
这是武夷岩茶复杂传统工艺的重要特征。

7.2 【最终游戏决定】
不拆成四个独立节点。
统一成为：
「炒揉」
但内部包含两轮：
第一轮：
炒青 → 揉捻

第二轮：
复炒 → 复揉
玩家感知为一次完整工序，但系统内部保留“两轮”的真实逻辑。

7.3 为什么这样设计
如果拆成：
炒青 → 揉捻 → 复炒 → 复揉
玩家会觉得：
“怎么又来了？”
增加操作负担，却没有增加足够的理解价值。
所以：
保留真实因果，压缩操作次数。

8. 焙火
8.1 【现实】
焙火是武夷岩茶形成最终风格的重要环节。
传统工艺强调：
低温久烘
而不是简单地：
“温度越高越好。”
不同茶叶状态、品种和制作目标会影响焙火处理。

9. 焙火小游戏——最终方案
9.1 核心机制
采用：
动态指针 + 火候区域
画面：
弱火 ─────── [ 合适区域 ] ─────── 强火
                    ↑
                  指针
                 ↗  ↘
指针不断摆动。
玩家需要在合适时机点击：
锁定火候。

9.2 重要真实性原则
绿色区域不要固定为一个绝对温度。
因为现实中：
焙火不是一个固定温度答案。
不同茶叶状态和目标会影响火候。
因此游戏表达的是：
判断火候是否合适
而不是：
“达到 120℃ 才正确。”

9.3 反馈
优秀：
“火候走得稳。”
良好：
“火走得还不错。”
普通：
“火有些急。”
失败：
“火候没压住。”

10. 三种茶：武夷山第一章的三个主角
10.1 总原则
三种茶必须让普通玩家能够快速区分。
不要使用：
香气 82 汤感 91 回甘 76
不要设计复杂专业评分。
玩家只需要记住三个核心印象。

10.2 肉桂
【现实特征】
肉桂是武夷岩茶重要品种。
最具辨识度的特点之一是：
桂皮香
相关资料还常描述其香气：
	•	辛锐
	•	浓郁
	•	高扬
	•	持久
具体香气表现还可能出现花香、果香、奶油香等变化。
【游戏定位】
🔥 张扬派 / 高香型
关键词：
桂皮香 / 辛锐 / 高香 / 香气明显
【玩家记忆句】
“肉桂，先闻香。”
【NPC语言】
“这茶还没入口，香已经先到了。”

11. 水仙
【现实特征】
水仙首先是一个茶树品种。
武夷水仙常见的品质描述包括：
	•	醇厚
	•	柔和
	•	汤感明显
	•	兰花香等
老丛水仙还可能出现消费者常说的：
丛香 / 枞味
但不能把“老丛 = 一定有某种固定香味”作为绝对规律。
【游戏定位】
🌿 温润派 / 汤感型
关键词：
醇厚 / 柔滑 / 汤感 / 兰花香
【玩家记忆句】
“水仙，喝的是汤。”
【NPC语言】
“水仙嘛，香不一定最张扬，汤得有东西。”

12. 大红袍
12.1 【现实特征】
大红袍是武夷岩茶最具代表性的名称之一。
需要特别注意：
不能把“大红袍”简单理解成固定的一种香气。
其具体表现可以有：
	•	花香
	•	果香
	•	花果香
	•	焙火香
	•	醇厚滋味
	•	岩韵等
商业市场中的“大红袍”也存在不同制作和拼配方式。

12.2 母树与商品大红袍必须区分
必须守住：
母树大红袍 ≠ 今天市场上所有“大红袍”的简单来源。
玩家在茶园里制作的：
“大红袍”
是游戏中的商品茶品类，不允许暗示玩家采到了九龙窠母树。
结果页可以轻描淡写地写：
“此大红袍，非九龙窠那几棵。”

12.3 【游戏定位】
🟤 平衡派 / 综合型
关键词：
变化 / 协调 / 岩骨花香 / 经典
玩家记忆句
“大红袍嘛，得喝了才知道。”
NPC语言
“肉桂，你一闻就知道。”
“水仙，你一喝就知道。”
“大红袍？”
“喝了再说。”

14. 禁止出现的三种茶表达
❌ 水仙“适合女性”
不能作为事实。
这是消费者/营销语言，不属于可靠茶学特征。

❌ 大红袍 = 肉桂 + 水仙
不能作为固定定义。
可以解释：
市场上存在拼配的大红袍。
但不能告诉玩家：
“大红袍就是肉桂和水仙拼出来的。”

❌ 牛肉一定比马肉好
“牛肉”“马肉”等是消费者/茶圈对于特定山场茶的俗称和表达。
可以作为地方茶文化素材。
不要在游戏里建立：
牛栏坑 = 数值更高 马头岩 = 数值更低
这样的绝对关系。

15. 茶叶结果系统
15.1 不使用专业评分
不要显示：
香气：86
滋味：91
汤感：82
回甘：88

15.2 最终结果
只显示：
【武夷岩茶 · 肉桂】

        上品

火候走得稳，
桂皮香已经出来了。

可售：38 茶钱

火功：中火

🎒 已收入茶篓

15.3 品质等级
建议：
失败 / 普通 / 良好 / 上品
不出现：
神品
MVP 取消“神品”
原因：
	•	概念边界不明确；
	•	容易引入稀有概率；
	•	会让玩家误解为现实茶叶专业等级；
	•	对第一章没有必要。
未来如果真的需要极稀有彩蛋，再另行设计。

16. 失败机制
最终决定
❌ 不扣茶钱
✅ 消耗「本轮鲜叶」（本轮采得的原材料，非长期库存；不存在"鲜叶 −1"的扣除逻辑）
✅ 失败仍产出成茶（失败等级，进入背包 / 茶叶记录）；想重制需再采一篓新的本轮鲜叶
失败应该产生：
“可惜。”
而不是：
“惩罚好重。”
例如：
“这锅茶……自己喝吧。”
玩家可以继续尝试。

17. 熟练度
最终决定
不显示具体数字。
不要：
熟练度：37
不要：
+5 熟练度
可以内部存在数值，用于控制系统，但前台不要展示。

前台显示
例如：
初学
↓
入门
↓
熟手
↓
老练
或者：
“最近做茶越来越稳了。”

18. 茶钱
茶钱是：
游戏经济系统
不是现实茶叶价格。
不要尝试复制真实市场价格。
真实资料只负责告诉我们：
为什么品质不同会影响价值。
具体游戏金额可以自由调整。

19. 泡茶——MVP 必须完成闭环
第一日必须包含泡茶。
因为核心闭环应该是：
采茶
↓
制茶
↓
得到茶
↓
泡茶
↓
喝自己做的茶
如果做到“制茶结束”就结束，玩家会感觉：
“我为什么要做茶？”
泡茶让整个第一日真正形成体验闭环。

20.1 现实认知
武夷岩茶常使用：
盖碗 / 紫砂壶等
进行多次冲泡。
盖碗冲泡是游戏 MVP 最适合采用的方式。

20.2 游戏流程
烧水
↓
温盖碗
↓
投茶
↓
注水
↓
判断出汤
↓
观察茶汤
↓
闻香
↓
品茶

21. 投茶量
资料中存在不同的常见建议。
因此：
不把某一个投茶比例写成唯一正确答案。
游戏中可以使用一个合理的固定范围作为：
游戏参数
而不是专业标准。
玩家不需要知道：
“必须精确到 8g。”

22. 出汤
22.1 游戏机制
设计：
动态出汤判断
玩家看到一个时间/状态指示。
在合适窗口点击：
出汤

22.2 现实逻辑转译
如果太慢：
“茶汤有些浓了。”
如果太快：
“香气还没完全展开。”
合适：
“这口汤，刚好。”

22.3 不固定死具体秒数
不同资料存在不同建议，实际冲泡也会受到：
	•	茶量
	•	水温
	•	器具
	•	焙火程度
	•	个人口味
影响。
因此：
秒数用于游戏平衡，不用于宣称专业标准。

23. 泡茶后的反馈
不要再做专业审评表。
可以直接：
肉桂
“桂皮香很明显，入口也有劲。”
水仙
“汤感柔下来，兰花香慢慢出来了。”
大红袍
“香、汤、火候都比较协调。”
玩家通过体验自然理解三者区别。

24. 六棵大红袍母树
24.1 游戏原则
母树是故事，不是资源。
绝不出现：
	•	去采母树
	•	母树采集
	•	母树稀有掉落
	•	母树坐标收集
	•	“采一片母树叶”
	•	“母树大红袍售价 ×100”

25. MVP 呈现方式
只做：
一段 NPC 对话 + 一张漫画
成本极低，但记忆点很强。

推荐 NPC 对话
玩家：
“这里的大红袍也能采吗？”
茶农：
“你说九龙窠那几棵？”
“早就不采啦。”
玩家：
“那现在喝到的大红袍呢？”
茶农：
“嘿，这个问题嘛——”
“慢慢喝，你就知道了。”

26. 母树知识卡
标题：
【茶山旧闻｜六棵母树】
内容保持短：
九龙窠曾有被称为“大红袍母树”的茶树。
母树大红袍与今天市场上的“大红袍”不能简单画等号。
母树已经停止采摘并受到保护。
真正的大红袍故事，不只是那几棵树。
不要塞过多历史考据。

27. 大红袍传说
27.1 使用原则
大红袍得名存在多个传说。
例如：
赶考书生 ↓ 天心寺 ↓ 茶治病 ↓ 进京赶考 ↓ 高中 ↓ 皇帝赐红袍 ↓ 披红袍于茶树
这一类内容可以做漫画。

27.2 必须标注
标题：
【传说】大红袍的名字怎么来的？
不要写：
“历史上的大红袍就是因为……”
而写：
“民间流传着这样一个故事……”

28. 水仙名称故事
水仙茶名称相关存在不同说法。
其中一种常见说法会将其名称与：
水仙花
联系起来。
但：
水仙茶 ≠ 用水仙花制作的茶。
这个可以作为一个很轻松的知识卡：
“你以为水仙是花？”
“其实它是茶树品种。”
非常适合《茶游记》。

33. 阿秀——采茶人
核心性格：

核心性格：

“急了。”

“有点样子了。”

36. 茶俗：喊山
36.1 核心事实
“喊山祭茶”是武夷山重要茶俗之一。

	•	祷茶
	•	祈求茶芽萌发

现代仍存在相关“喊山祭茶”活动，并被纳入地方非遗保护体系。

39. 斗茶
39.1 现实文化
斗茶是中国茶文化中的传统茶事活动，在武夷山茶文化中具有重要地位。
其核心可以理解为：
拿茶出来比较。
历史上涉及茶叶品质、冲泡、汤色、香味等方面的比较。

40. 《茶游记》中的斗茶
MVP：
不做完整系统。
只做：
文化伏笔。
例如：
NPC：
“做茶做得好不好，自己说了不算。”
“得拿出来喝喝。”
“这就叫斗茶。”
出现：
🔒 斗茶
提示：
“等你再认识几种茶，再来。”

48. 第一章玩家最终应该记住什么
离开武夷山时，玩家不需要记住所有专业术语。
只需要记住：

第二层
做青很重要。
第三层
焙火不是越猛越好。
第四层
肉桂、水仙、大红袍不是一个味道。
第五层
武夷山的人真的把茶当成日常生活的一部分。
第六层
“原来武夷山的茶是这么做出来的。”
然后产生：
“那杭州的茶又是什么样？”
这才是《茶游记》真正的下一步驱动力。

49. 三种茶的游戏参数——开发注意
V0.3 曾设计过：
肉桂做青偏重、水仙偏中、大红袍要求均匀； 肉桂炒青安全区窄、水仙宽、大红袍中； 不同茶焙火区域不同。
V1.0 最终建议：
不要把这些参数包装成现实茶学事实。
如果开发测试证明需要差异，可以作为：
游戏参数
存在。
例如：
teaGameProfile = {
  rougui: {
    playStyle: "高香型",
    difficulty: "medium"
  },

  shuixian: {
    playStyle: "醇厚型",
    difficulty: "easy"
  },

  dahongpao: {
    playStyle: "综合型",
    difficulty: "medium"
  }
}
而不是：
rougui.requiresMoreShaking = true
并在知识系统里告诉玩家：
“肉桂现实中一定要重摇青。”
不要这样。

50. 游戏化内容与事实内容分层
建议代码层面明确区分：
interface TeaFact {
  text: string;
  level: "S" | "A" | "B" | "C";
  source: string;
}

interface TeaCopy {
  text: string;
  kind: "npcOpinion" | "gameHint" | "flavor";
}
例如：
“武夷岩茶传统工艺包含双炒双揉”
→ TeaFact

“这锅茶，拿出去待客也不丢人。”
→ TeaCopy / npcOpinion

“这茶还没入口，香已经先到了。”
→ TeaCopy / flavor

“水仙适合女性”
→ 禁止

51. 资料中存在争议 / 不应说死的内容
51.1 大红袍名称来源
属于传说体系。
必须写“传说”。

51.2 六棵母树的具体历史细节
不同资料对于母树数量、品系、历史传承等细节存在不同表述。
游戏只保留：
“大红袍母树受到保护，已经停止采摘。”
具体细节如非必要，不要扩大。

51.3 大红袍是否“就是拼配”
不能绝对化。
正确：
市场上存在拼配大红袍。
错误：
所有大红袍都是肉桂和水仙拼配。

51.4 水仙是否“适合女性”
禁止作为知识内容。

51.5 牛肉 / 马肉
可以作为：
茶圈俗称 / 地方消费文化
但不要变成：
固定品质等级。

51.6 冲泡秒数
不要写成唯一标准。
游戏中使用的是：
可玩参数。

51.7 投茶量
同样不要写成唯一正确值。

56. 最终开发原则
WorkBuddy 在实现任何茶文化内容前，先问三个问题：
① 现实中有没有？
如果没有：
不要为了玩法硬编。
② 为什么重要？
如果现实中有，但对玩家理解没有帮助：
可以简化。
③ 游戏简化以后有没有破坏因果？
如果没有：
可以简化。
如果破坏：
重新设计。

57. 最重要的一句话
不是把现实中的茶制作过程完整搬进游戏，而是让玩家通过游戏，感受到现实中的茶为什么会变成现在这个样子。
